# EdgeOps ESP32-C3 native node

Minimal ESP-IDF firmware for validating the native-device Wi-Fi and MQTT identity path. See [`docs/FIRMWARE_C3.md`](../../docs/FIRMWARE_C3.md) for setup, configuration, build, flash, and EMQX validation.

The firmware intentionally has no GPIO, sensors, commands, provisioning, or telemetry persistence.
